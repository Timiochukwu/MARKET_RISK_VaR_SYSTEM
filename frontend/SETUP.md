# 🚀 Frontend Setup Guide

## Step-by-Step Installation

### 1. Navigate to Frontend Directory
```bash
cd frontend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Install shadcn/ui (Interactive)
```bash
npx shadcn-ui@latest init
```

**Answer the prompts:**
- Would you like to use TypeScript? › **Yes**
- Which style would you like to use? › **Default**
- Which color would you like to use as base color? › **Slate**
- Where is your global CSS file? › **src/app/globals.css**
- Would you like to use CSS variables for colors? › **Yes**
- Where is your tailwind.config.js located? › **tailwind.config.ts**
- Configure the import alias for components? › **@/components**
- Configure the import alias for utils? › **@/lib/utils**
- Are you using React Server Components? › **Yes**

### 4. Install Required UI Components
```bash
# Install all components at once
npx shadcn-ui@latest add button card badge dialog dropdown-menu tabs table select slider switch toast sonner separator scroll-area avatar checkbox label input textarea popover radio-group progress tooltip accordion alert-dialog hover-card
```

### 5. Create Required Provider Files

**Create `src/components/providers/theme-provider.tsx`:**
```bash
mkdir -p src/components/providers
```

```tsx
// src/components/providers/theme-provider.tsx
'use client'

import * as React from 'react'
import { ThemeProvider as NextThemesProvider } from 'next-themes'
import { type ThemeProviderProps } from 'next-themes/dist/types'

export function ThemeProvider({ children, ...props }: ThemeProviderProps) {
  return <NextThemesProvider {...props}>{children}</NextThemesProvider>
}
```

**Create `src/components/ui/sonner.tsx`:**
```tsx
// src/components/ui/sonner.tsx
'use client'

import { Toaster as Sonner } from 'sonner'

export function Toaster() {
  return (
    <Sonner
      className="toaster group"
      toastOptions={{
        classNames: {
          toast:
            'group toast group-[.toaster]:bg-background group-[.toaster]:text-foreground group-[.toaster]:border-border group-[.toaster]:shadow-lg',
          description: 'group-[.toast]:text-muted-foreground',
          actionButton:
            'group-[.toast]:bg-primary group-[.toast]:text-primary-foreground',
          cancelButton:
            'group-[.toast]:bg-muted group-[.toast]:text-muted-foreground',
        },
      }}
    />
  )
}
```

### 6. Create Environment Variables
```bash
cp .env.example .env.local
```

Edit `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000/ws
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

### 7. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) 🎉

If you want to automate the process:

```bash
# Run this from frontend directory
npm install && \
echo "NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000/ws
NEXT_PUBLIC_SITE_URL=http://localhost:3000" > .env.local && \
mkdir -p src/components/providers && \
npm run dev
```

## Troubleshooting

### Issue: Module not found errors
**Solution**: Run `npm install` again

### Issue: Tailwind styles not loading
**Solution**:
1. Check `tailwind.config.ts` paths
2. Restart dev server: `npm run dev`

### Issue: Theme not working
**Solution**: Make sure `theme-provider.tsx` is created correctly

### Issue: Port 3000 already in use
**Solution**:
```bash
# Use different port
PORT=3001 npm run dev
```

### 2. Create API Client

```bash
mkdir -p src/lib
touch src/lib/api.ts
```

Example `src/lib/api.ts`:
```typescript
import axios from 'axios'

const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
  headers: {
    'Content-Type': 'application/json',
  },
})

export const varAPI = {
  calculateVaR: (params: any) => api.post('/api/v1/var/calculate', params),
  getPortfolio: () => api.get('/api/v1/portfolio'),
  getBacktest: (id: string) => api.get(`/api/v1/backtest/${id}`),
}

export default api
```

### 3. Create Custom Hooks

```bash
mkdir -p src/hooks
touch src/hooks/use-var-data.ts
```

Example `src/hooks/use-var-data.ts`:
```typescript
import useSWR from 'swr'
import { varAPI } from '@/lib/api'

export function useVaRData() {
  const { data, error, isLoading } = useSWR(
    '/api/v1/var/calculate',
    () => varAPI.calculateVaR({ /* params */ }),
    {
      refreshInterval: 5000, // Refresh every 5 seconds
    }
  )

  return {
    varData: data?.data,
    isLoading,
    isError: error,
  }
}
```

### 4. Add Charts

Install chart library:
```bash
npm install recharts
```

Create chart component:
```bash
mkdir -p src/components/charts
touch src/components/charts/line-chart.tsx
```

## Performance Tips

1. **Use Server Components** - Default in Next.js 14
2. **Lazy Load Heavy Components** - Use `dynamic()`
3. **Optimize Images** - Use `next/image`
4. **Code Splitting** - Automatic in Next.js
5. **Font Optimization** - Use `next/font`
