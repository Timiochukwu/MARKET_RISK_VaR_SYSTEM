## 🎯 QUICK START GUIDE

### **If You Want to Start NOW:**

**Step 1: Choose a Project**
```bash
# Option A: VaR System (easiest)
cd market-risk-var

# Option B: DeFi Analytics (harder)
cd defi-analytics-platform

# Option C: Unified Platform (combined)
cd unified-risk-platform
```

**Step 2: Install Backend**
```bash
# Install Python packages
pip install -r requirements.txt

# Run backend
uvicorn src.api.main:app --reload
# Or for unified:
uvicorn backend.api.unified_api:app --reload
```

**Step 3: Install Frontend**
```bash
cd frontend
npm install
npm run dev
```

**Step 4: Open Browser**
```
VaR System: http://localhost:3000
DeFi Analytics: http://localhost:3001
Unified: http://localhost:3002
```

**That's it! You're running the system!** 🎉
